## <a id="english"></a>English

### Overview
Fortnite-LobbyBot-v3 is the official successor to Fortnite-Lobby-Bot-v2 (gomashio1596). Created as a continuation of the original project based on a community fork ([Not-Bay/Fortnite-LobbyBot-v2](https://github.com/Not-Bay/Fortnite-LobbyBot-v2)), it combines nostalgic functionality with modern improvements using AI technology.

> ⚠️ **Project Status: Work in Progress (WIP)**  
> This project is currently under active development. Not all files, features, or documentations are fully complete yet, and some implementation details may remain experimental or incomplete. Updates and additions are being pushed regularly.  
> **Stay tuned for future developments and updates!**

### Key Features
* **Modern Engine**: Built on the latest `rebootpy` library for optimal performance.
* **Easy Customization**: Change cosmetics, manage lobby settings, and control the bot with simple commands.
* **Active Support**: Join our Discord community for setup help and announcements.

### Requirements
* Python 3.14 or higher

## <a id="日本語"></a>日本語

### 概要
Fortnite-LobbyBot-v3 は、人気を博した Fortnite-Lobby-Bot-v2 (gomashio1596) の正統な後継プロジェクトです。有志によるフォーク（[Not-Bay/Fortnite-LobbyBot-v2](https://github.com/Not-Bay/Fortnite-LobbyBot-v2)）をベースに、AI技術を活用して従来の利便性を残しつつ現代の環境へアップデートしました。

> ⚠️ **開発状況について（絶賛開発中 / WIP）**  
> 現在も絶賛開発進行中です。まだ全てのファイルや仕様が完璧に揃っておらず、一部未完成・曖昧な部分が残っています。順次、機能追加やコードの改善を行っています。  
> **今後のアップデートやさらなる進展にぜひご期待ください！**

### 主な特徴
* **最新ライブラリ対応**: 最新の `rebootpy` をベースにしており、安定したロビー操作が可能です。
* **手軽なカスタマイズ性**: コマンド操作でスキンやエモートの変更、ロビー設定を簡単に変更できます。
* **手厚いサポート体制**: 公式Discordサーバーで導入手順の確認やコミュニティでの交流が可能です。
